  WorkerBadge
    발급 (issue)
      ✔ 발급기관이 배지를 발급하면 작업자가 소유하고 이벤트가 남는다
      ✔ 발급기관이 아니면 발급할 수 없다
      ✔ 주소 0 과 이미 지난 만료일은 거부한다
      ✔ 같은 종류의 유효한 배지가 있으면 중복 발급을 거부하고, 만료 후에는 재발급할 수 있다
      ✔ 관리자가 발급기관을 추가할 수 있다
    양도 불가 (Soulbound)
      ✔ 전송·승인 시도는 모두 거부된다
      ✔ ERC-5192 인터페이스를 지원한다고 알린다
    폐기·갱신 (revoke / renew)
      ✔ 폐기하면 즉시 무효가 되고, 폐기된 배지는 연장할 수 없다
      ✔ 연장은 기존보다 늦은 날짜로만 가능하다
      ✔ 없는 배지는 BadgeNotFound
    장비 접근 판단 (isQualified)
      ✔ 지게차는 지게차 면허 + 안전교육이 둘 다 유효해야 한다
      ✔ 규칙이 없는 장비는 기본 거부, 관리자는 규칙을 바꿀 수 있다
    장비 검증기 (오프체인 challenge-response)
      ✔ 정상 서명은 허용, 같은 서명 재사용은 거부
      ✔ 다른 장비용 challenge 에 대한 서명은 이 장비에서 통하지 않는다
      ✔ EIP-712: 다른 컨트랙트(배포본)용으로 만든 서명이나 만료 시각을 고친 서명은 통하지 않는다
